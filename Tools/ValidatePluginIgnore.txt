# Regexes for editor startup log lines that ValidatePlugin.ps1 should NOT report.
# One pattern per line, matched against "Category: Severity: Message". Lines starting with # are comments.
#
# Use this for engine noise that also appears in a project without the plugin, e.g.:
#   ^LogAudio: Warning: .*
#   ^LogDerivedDataCache: Warning: .*Shared.*
#
# Keep patterns specific so genuine plugin problems are still caught.

# Build agents run as a service with no interactive desktop, so IME setup always fails
^LogWindowsTextInputMethodSystem: Warning: Initialization failed while creating the IMM context\.
# The Water plugin (pulled in by plugin dependencies) wants a project-level collision profile the empty project doesn't define
^LoadErrors: Error: Collision Profile settings do not include an entry for the Water Body Collision profile
